### 4.5 Type rules (owner 2026-10-29, after the B build)

On a production capture of the signed-in home page ("do these fonts look too different") and of /bis/mage/fire ("a modern font and then a book type of font"), three rules replace the Numbers row above and bind every surface:

1. **One body face for every number.** The code face (JetBrains Mono) is retired from UI text. Every number, date, count, stat, timer and label that was mono ("15 upgrades", the Dates strip, the BiS band buttons, the This set figure, the stat weights columns, report and roster tables) is the `numeric` recipe: Barlow with `font-variant-numeric: tabular-nums`, so columns and timers still align. Headline figures stay in the heading face (`figure-stat`, `figure-price`). Mono stays only on literal code: export strings, slash commands such as `/fs copy`, file names, pairing codes, ids, build strings and anything a player copies or pastes (`web/src/styles/mono-face.test.ts` lists each use).
2. **One heading-case rule.** Page, section and card titles are uppercase in the heading face (`heading-hero`, `heading-page`, `heading-section`, `section-title`). A value or title inside a card (a character name, "Unoptimized", "Premium", a plan name, a class card's name) is the heading face in its copy's own case (`heading-plan`, `heading-name`): no CSS forces it uppercase, so "Obnoxious Yell" reads as written.
3. **Tracked caps on card eyebrows only.** Gold tracked uppercase (`label`) is for a card's eyebrow (YOUR CHARACTER, TALENTS, SIMULATOR, PLAN, UPGRADES FOR YOUR LEVEL RANGE). Every form field label (Character name, Region, Ruleset and the rest) and every data-table column header (Slot, You wear, Best in slot, Gain and every report, roster, tier and sim table) is the `quiet-label` recipe: `--muted`, sentence case, regular tracking, 13 px 600. Slot row labels in the BiS and upgrade tables take it too. An insignificant stat weight reads "Not significant" once, muted, on one line across the three figure columns.

## 6. Performance and polish limits (whole lane)

- Lighthouse budgets in `web/lighthouserc.json` are unchanged and binding: CLS at most 0.05 with 0 the target, LCP at most 2400 ms on the default row.
- The new heading face is self-hosted, latin subset, the single heaviest weight preloaded, over a size-adjusted fallback, so the swap moves no line (tenet 13). The lane records the measured CLS of /, /premium and /account before and after.
- No component adds client JavaScript to a static page: `Switch` and `SettingsRow` are Svelte for islands that already exist, with `.astro` twins for static pages. /premium still ships no `_astro` script.
- Icons carry width and height everywhere they appear; a failed icon hides on `error`; no missing-icon flash.
- Reduced motion turns off the switch slide, the chevron nudge and the glow transitions.
