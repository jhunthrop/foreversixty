# Sim audit, round 5: physical group (2026-11-01)

Arms, Fury, Protection, Assassination, Combat, Subtlety, Beast Mastery, Marksmanship and Survival (melee). Client 1.60.1.70707. Baseline: engine pin f8a5f94ce with a simdb.bin regenerated from origin/main's pipeline (round 4's item fixes included). Fixes are on fork branch `lane/r5-physical` (E) and site branch `wt/r5-physical` (S). The fork branch also carries the casters lane's racial commit (e4d9ff60c, cherry-picked as 6c4f13ebd), as the integrator asked; it is not this lane's work. Measurements use `sim/cmd/spec-breakdown`, raid preset, band 60, 10000 iterations, seeds 1 and 50001. The "after" simdb.bin is regenerated locally from this branch and is not committed, because the nightly owns it.
