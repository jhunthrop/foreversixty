## Gotchas
- **Toolchain**: `JAVA_HOME=/opt/homebrew/opt/openjdk@21 ANDROID_HOME=/Users/jh/Library/Android/sdk ./gradlew ...`; run only touched tests; `:app:lintDebug` is strict (NewApi: `Duration.toMinutesPart` is API 31; unused drawables).
- **Measuring a mock**: render the HTML in `design/mocks/app/` with Playwright and dump every element's box relative to `<main>`; that is how the primitives' paddings were set (rows 10/6, item rows 8, section head 24 + 10 + rule, block 24 above, section 28 above). Never commit a Mac render.
- **Trailing lambdas**: `FlowRow`'s last parameter is `onClick`; pass a trailing control as `trail = { ... }`.
- **Text taller than its line** (Barlow 40/42 clock): use `Modifier.lineBox(style.lineHeight)`.
- **Goldens are recorded on CI, never locally** (`gh workflow run android.yml --ref <branch> -f record=true`, `gh run download <run> -n android-snapshots -D apps/android/app/src/test/screenshots`). `ParityCheck` now captures the image before comparing, so a local `recordRoborazziDebug` leaves the capture to read even when the regions fail; delete those PNGs before committing (the `.txt` goldens are renderer independent).
- **Copy**: append keys to `apps/shared/copy/en.json` keeping its hand formatting (a new blank-line group), no `%` (pass `8%` as an argument), then `node web/scripts/gen-mobile-copy.mjs`.
- **Scratchpad**: prefix files with `android6-lane-`; earlier lanes used `android-lane-` to `android5-lane-` (lane 5's sub-lanes `android5-<family>-`).
- **Measuring a mock locally**: this worktree's `web/node_modules` may be missing; import Playwright by absolute path from a worktree that has it (`.../web/node_modules/playwright/index.mjs`).
- **Gradle in a worktree**: pass `--no-watch-fs`, or a new source file can be missed (`No tests found`).
- **core:auth on CI**: `SessionManagerTest`'s dead-token watcher runs on `Dispatchers.Default` (UNDISPATCHED); a watcher on the test scheduler starved under the wall-clock wait and timed out on every CI verify.
- **Launch mode** skips `android.yml` on `land/**`; run the record on a non-land branch first and land only a green tree.
- **Run web.yml before every go**: android.yml and ios.yml do not run prettier; lane 4's copy codegen change failed land/android-home-gear on `format:check`.
- **The iOS runner** has lost its simulator runtime (`Unable to boot device`, `iOS Simulator (null) doesn't match`); rerun the failed job (`gh run rerun <id> --failed`). ios.yml now ensures the simulator before testing (241a48a4a), and iOS snapshots compare within 5 levels per channel (638864c3d).
- **land.sh can stall** printing `N runs, 1 running` after every run finished (a stale read under the GitHub rate limit): check `gh api repos/jhunthrop/foreversixty/actions/runs?head_sha=<full sha>`; if all are done, kill it and rerun `tools/land.sh land/<name>`.
- **GitHub rate limit**: every lane shares one token; poll no faster than every 3 minutes (`gh run watch <id> --interval 180`), never loops of `gh run list`.
- **zsh**: `"$sha:refs/..."` applies the `:r` modifier; write `"${sha}:refs/heads/${land}"`.
- **en.json merges**: take the union of keys, then regenerate; lane 5's resolver is `android5-lane-enjson-union.py` in the session scratchpad (top-level keys only, fails on a key defined twice with different values).
- **Generated files**: never hand-edit `navigation/DeepLink.kt` or other generated code; links come from `links.json` (the raid `view=unanswered` constant lives in `navigation/RaidLinkView.kt`).
- **Fixture text on a wrap edge**: a sentence within a few dp of its column wraps on the Linux mock render and not on Android (bis-spec-healer-60's "Glowing Brightwood Staff is a two-hander..." measures 379.05 dp in 380). Never add an inset to pass the gate; change the data both sides read or take it to the coordinator.
