# Plan under review: three raid-week guild features (2026-11-14)

Read 00-facts.md first: it is what the code can and cannot do.

1. Loot plan before the raid. For each boss of the night: each drop, and which signed-up raider gains most (the loot-value rule: stat delta times the sim's DPS per point at the raider's band; HPS for healers, score for tanks), adjusted for recent wins and attendance (the council's last-4-raids window). Gear from the addon export where present (newest), else signed-in Blizzard data (3 h / 20 h, enchants), else the directory (up to 72 h, no enchants or suffixes). Every row says where its gear came from and how old it is. Surfaces: web guild Raid/Loot page, Discord post before the raid, app Raid tab, the raid leader's addon during the loot session (loot! already compares live).
2. Live pull reports. In game: the raid leader's addon explains each pull from live combat events (no companion). Site, second screen and phone: one companion in the raid uploads each fight as it closes (seconds); the site explains what cost most, with names: deaths to a mechanic, missing protection potions (only when the log carries the character sheet), downtime, rotation losses. Night summary = sum of pulls. Several companions: one is chosen.
3. Prep reminder one hour before. Off game (Discord DM or phone push): only Blizzard-profile data (gear, enchants and resistance gear for signed-in members) plus bags from the raider's last companion upload, labelled with its age. In game: the raider's own addon checks bags at T-1h and shows the raider directly. Relay design: raider addons send their checks over GUILD/RAID; addons whose player runs the companion announce themselves as relays; the relay collects everyone's checks; its companion carries them up, but only via SavedVariables, so v1 is a relay-only "Send tonight's prep" button that reloads the UI. Officers see one list: checked (with time) and cannot check. Several relays: dedupe. No relay: said plainly.
Later: 4 comp and bench call (raid-wide buffs, coverage plus marginal sim gain), 5 recruiting search over the directory (opt-outs, privacy notice).
