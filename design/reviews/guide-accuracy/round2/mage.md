## Decisions

- **D1. Source labels name the source in player words, never a file path.** Every guide `sources` label with a `kind: site` entry reads `Forever Sixty, <what it is>`, with no repo path, file name, `.json`, `data/`, or pipeline nouns ("rotation data", "build data", "APL", "preset", "sim"). Reason: the labels are frontmatter strings shown verbatim in the Sources footer, which is the one place provenance belongs (feedback-provenance-quiet), and the footer is player-facing copy under the same voice rule as the body (feedback-guide-voice). The clean form already exists in hunter (`'Forever Sixty, stat weights'`). Mapping for every class: stat-weights.json / specs.json → `Forever Sixty, stat weights`; apl/<spec>.json → `Forever Sixty, rotation`; loot/forever-raid-phases.json (both "raid loot data" and "raid phase data") → `Forever Sixty, raid loot tables`; talents/<class>.json → `Forever Sixty, talent trees`; spellconst/<class>.json → `Forever Sixty, spell values`; races.json → `Forever Sixty, racial abilities`; combos.json → `Forever Sixty, race and class pairs`; tank-encounter.json → `Forever Sixty, tank fight`. Today 42 labels carry a path (druid, hunter, mage, paladin). Add a `_prose.test.ts` check that no `sources[].label` contains `.json` or `data/`. Mage rewrites: MAGE-R2-8.

## Sim findings

- **SIM-R2-1 (Arcane Wrath).** Add Arcane Wrath to both Arcane builds (1 point; Wand Specialization 1 is the free point in the raid string, and the tier 3 gate still holds with 18 points above it) and to mage-arcane.json: cast on cooldown at 3 or more Blast stacks, Presence of Mind on Arcane Wrath instead of Frostbolt. Measure on the 60 raid band; consensus (Warcraft Tavern, Mobalytics, Wowtbc, Icy Veins) expects a clear gain. Then apply the R2-1 follow-up prose.
- **SIM-R2-2 (Arcane raid build: Fire or Frost subspec).** Mobalytics Verified Arcane gives 32/16/3 (Arcane with Incineration 5, Accelerant 2, Ignite 5, Pyroblast, Improved Fire Blast 2, Heating Up, Precision 3) as "the expected raiding build for Arcane mages", and Icy Veins Forever Arcane says competitive Arcane plays a Fire subspec (Fire Blast, Arcane Wrath, Pyroblast on 3 Heating Up). The talent search could not test it: its deep-Fire candidates scored the Fire talents "modeled, no damage" because mage-arcane.json casts no Fire Blast or Pyroblast. Question: with an Arcane/Fire APL (Pyroblast on 3 Heating Up, Fire Blast on cooldown, Missiles on Barrage, Arcane Wrath on cooldown, Blast filler), does 32/16/3 beat the guide's 32/3/16 on the 60 raid band? If it does, the build, the Talents section and the filler text change together.
- **SIM-R2-3 (Fire leveling filler).** See MAGE-R2-7: Scorch vs Fireball filler at ladder levels 25 and 30.
