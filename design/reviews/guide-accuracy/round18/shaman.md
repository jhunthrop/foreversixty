How the card gate resolves per level (engine da54b7b06): at 0 points `applyMaelstromWeapon` returns before registering any aura, so `not auraIsKnown(408498)` holds and the reserve is a quarter. At 5 points the trigger aura carries tag 5, so the reserve is a quarter. `ActionID.SameAction` compares the tag (`sim/core/agent.go:76`), so the three branches resolve as the sim lane intended; not a sim finding.
