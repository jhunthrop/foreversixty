## Decisions

1. **Heeding the Call "teaches Bear Form" stays.** In-game it is the first quest of a short chain. Both Forever leveling guides present it as the Bear Form quest, and a new player only needs to know where to pick it up, so the wording is not false.
2. **Cure Poison at 14 stays as written.** In Forever (as in 1.12) it comes from the "Lessons Anew" quest rather than a straight trainer buy (Method, Warcraft Tavern). "Cure Poison at 14" is still true. Naming the quest is optional polish, not a fix.
3. **Site source links (DRUID-R4-1): use the live tool pages, never /sources, for a label that names a tool.** /sim/weights for weights and /sim/drops for loot. For "rotation" and "tank fight", use /sim/specs with a "how X plays" label, as the warrior pages do. The same pattern sits on the mage, warlock, paladin and warrior pages (`grep -l "foreversixty.gg/sources" web/src/content/guides/*/*.md`), so the integrator should fix it in one pass for every class.
4. **The Skyborne forms "sky-blue" (index.md:36) stays,** because the sources describe the forms on a blue and white palette.
