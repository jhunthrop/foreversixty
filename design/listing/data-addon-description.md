## Description

## Ratings and guild standings, in game

Forever Sixty Data is the companion data pack for the **[Forever Sixty](https://foreversixty.gg/addon)** addon. It carries the latest performance ratings and guild standings from **[foreversixty.gg](https://foreversixty.gg)** into the game, so you can see how a player or a guild performs without leaving your raid frames.

It contains no code of its own. Install it beside Forever Sixty and the addon reads it. Without Forever Sixty it does nothing.

### What is in it

- **Player ratings.** One number for a character's whole performance across their public logs, with the six parts behind it: output, survival, mechanics, utility, preparation and activity. A parse is not a performance, and this rating says so.
- **Guild standings.** Progress, raid nights and roster size for guilds that raid with logs on the site.

### How it stays current

A new version is published **every night** after the site processes the day's logs. Update it through your addon manager the same way as any other addon, and the numbers in game match the site.

### Where the numbers come from

Every rating comes from combat logs uploaded to foreversixty.gg with public visibility, rated by the same engine the site uses. Private and guild-only logs are never included. The site's **[ratings page](https://foreversixty.gg/ratings)** explains each part of the rating and how small samples are handled.

### What it does not do

It never connects to the internet, reads nothing from your account, and does nothing in combat. It is a file the game loads, updated by your addon manager.
