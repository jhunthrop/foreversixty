# Polish lane Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** make the live site read as a modern gaming product: direction B type and surfaces, an account control in the header, a footer with hierarchy, one component set, /premium without the empty example card, and the ranked polish inventory worked through.

**Architecture:** tokens first (one commit everything else reads), then four independent surfaces in parallel, then the inventory by rank. Every piece is reviewed by the ux-designer and the wow-player on captures of the live site and pushed to main on its own.

**Tech Stack:** Astro 5 + Svelte 5 + Tailwind, vitest, Playwright, lhci.

**Spec:** `design/specs/2026-10-28-polish.md` (authority), mocks under `design/mocks/2026-10-28-polish/` (direction **B · Forge**, picked by the owner 2026-10-28 19:35).

## Global Constraints

- Tenets in `docs/tenets.md`: the best-addon standard, one crest language, full-bleed bands, centred max-width containers, 44 px targets, no layout shift (reserves pinned by `layout-reserve.test.ts`), the owner reads at ~2000 px.
- Direction B only: `--font-heading` = Barlow Condensed 700/800; `--font-display` (Cinzel) only in the wordmark; body stays Barlow; surfaces and radii per spec §4.2/§4.4.
- Copy keys live in the copy modules the spec names; a copy change edits the spec row and the module together.
- Performance budgets in `web/lighthouserc.json` hold (fonts must not push LCP).
- Nothing ships with a placeholder; the example card is gone (spec D4).

## Review Focus

1. A heading somewhere still in Cinzel (the sweep missed a bespoke style) — Task 1's test pins it.
2. The account control on phone: the panel must fit 360 px with every row a 44 px target — Task 2.
3. The footer's link columns on phone collapsing into one unreadable column — Task 3.
4. Switches must be keyboard-operable and announce state — Task 4's a11y test.
5. The sample coach review on /premium must never read as a real player's review — Task 5 pins the `Sample` tag and caption.
