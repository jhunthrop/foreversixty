# bnet-api: Battle.net character import, guild discovery, `/v1/me/exports`

Lane `bnet-api`. Spec (binding): `docs/superpowers/specs/2026-09-22-battlenet-character-import-design.md`,
sections 1-6. Owns `api/**` and this plan file. Section 7 (`web/**`) is `bnet-web`'s.

## Global constraints (copied from spec section 1, plus file ownership)

1. Never persist a Battle.net user access token anywhere. Client-credentials tokens: memory only.
2. Never log a token, a `code`, or a `state`.
3. Namespace/region are configuration (`BNET_PROFILE_GAME`, `BNET_REGIONS`), never literals.
4. A Blizzard roster is authoritative over an export: `source='bnet'`/`verified_by='bnet'` rows
   are never downgraded by an export naming the same guild.
5. `characters` becomes the single list of an account's characters, written by every path that
   learns one (bnet import, companion export, signed-in paste).
6. `.superpowers/journeys/lane-common-go.md` binds: worktree isolation, sonnet-only subagents,
   commit format, scoped `go vet`/`go test` before every commit.
7. File ownership: `bnet-api` owns `api/**` and this plan file only. Never touches `web/**`.

## Tasks

1. Migration `0024_bnet_characters` (up/down), matching `0018`'s real constraint names.
2. `character` package: no changes needed (`Key`/`RulesetFromRealm` already fit).
3. `guilds` package: extract `ResolveGuild`, `DeriveRank`, `AfterGuildChange`,
   `UpsertCharacterMembership` (exported) from `addon.syncGuild`'s unexported helpers; `addon.go`
   calls the exported versions (no behavior change — verified by existing addon tests staying
   green).
4. `bnetapi` package: `Client`, namespaces, `AppToken`, `Realms`/`RulesetOf`, `AccountCharacters`,
   `Character`, `GuildRoster`, `Probe`, typed errors, httptest fixtures.
5. `bnetimport` package: `ImportAccount` (4.2), collision handling, guild sync via `guilds`
   exported helpers, `RefreshJobCommand` nightly job (4.4) + probe logging (section 5).
6. `auth` package: `BnetUser.AccessToken` (never serialized/logged), `Importer` interface +
   wiring on `Service`, `bnetCallback` calls `Importer.ImportAccount` with a 5s budget, never
   fails login. `characters`/`Me` read-side additions for section 6's JSON. `users.bnet_imported_at`.
7. `addon` package: `ParseFS1Class`; `putOneExport` also upserts `characters`; new
   `POST /v1/me/exports` (session, rate-limited); `addon.Mount` gains `trustedProxyHops`.
8. `config` package: `BNET_PROFILE_GAME`, `BNET_REGIONS`, `BNET_PROBE_GAMES` + defaults.
9. `main.go`: wire `Importer` behind `config.Configured()` for Battle.net; `bnet-refresh` job
   command.
10. `api/README.md`: env vars + `bnet-refresh` job recipe (copy `data-addon`'s shape).
11. `.github/workflows/api.yml`: add `bnet-refresh` to the "Point the jobs at the new image" list.
12. Whole-branch scoped `go vet`/`go test`, final `go test ./...`.

Executed directly (single implementer, no per-task subagent dispatch, given the tight coupling
across packages); ledger of rulings is in this plan's own commit history and the final report.
