Added Discord notifications. Premium members can paste a Discord webhook on the account page and get a message when a server sim finishes or a log finishes parsing. Pick which of the two you want, and send a test message to see it arrive. The link is encrypted and never shown again; the page only shows which channel it posts to.

If Discord refuses five posts in a row, the messages switch off and the account page says why. Fix the channel, press Test and switch on, and they resume. If your plan ends, your webhook is kept and posts start again when you are back on Premium. You can remove the webhook at any time. Free members see one line pointing to the plans, and the Premium rows on the account page now show whether Discord messages are on. Private logs only post if you turn on Include private logs, and the account page now shows the name of the webhook, so you can tell which channel it is.
