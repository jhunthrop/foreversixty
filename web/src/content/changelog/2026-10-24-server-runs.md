Premium members now see their server runs at the top of the Simulator: each run's name, spec and state, with an estimate for a running one drawn from the last ten finished runs of that spec, the result for a finished one, and the plain reason for a failed one with a Run again button. Runs start the moment they are sent, so there is no queue and nothing to cancel.

A run that finishes while no tab is open is announced once in the character band on the next page load, with a link to the result. Opening the result or dismissing the line clears it. The account page's Server sims row now counts this month's runs.
